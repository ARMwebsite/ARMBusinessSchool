# ARM Business School

The website of ARM Business School, Karachi: PRC, CAF, CFAP and the Strategic Case Study, with every mock marked to the ICAP standard.

**Live site:** published with GitHub Pages from this repository.

## What is here

| File | Purpose |
|---|---|
| `index.html` | The complete website: every page, photo and animation in one file |
| `.nojekyll` | Tells GitHub Pages to serve the file as it is |

## Updating the site

1. Open `index.html` in this repository and choose **Add file → Upload files**.
2. Drop in the new `index.html` and press **Commit changes**.
3. The live site updates within a minute or two. The link stays the same.

Day-to-day text changes (fees, faculty, results, FAQs) can also be made in the site's built-in editor. Export the JSON from the editor and have it built into a new `index.html`.
